# RULES — given by the owner (ayoub5550). Binding for every agent.

1. **Never create, always collect.** Do not model, rig, animate, compose music or design sounds yourself. Search for a free ready‑made asset first. Quality comes from real assets, not from agent‑made placeholders.
2. **Templates first.** Start every project from an existing template/repo (game controller, scene, UI, camera rig) and glue with the least possible custom code. Disclose exactly how much code you wrote.
3. **Realistic characters only.** No low‑poly / cartoon / blocky humanoids unless the owner asks for that style. Mixamo, Sketchfab (realistic, CC), CGTrader free are the default sources.
4. **Free & licensed.** Every asset must be free to use in the project. Prefer CC0 → CC‑BY (credit it) → site‑specific free licenses (Mixamo, Pixabay, Mixkit). Read the license of the *specific file*, not the site's homepage. No trademarked IP (e.g. Capcom names/assets) — "inspired by" only.
5. **Accounts.** If a source needs an account, first check `ACCOUNTS.md`; if none exists, register with `ayoubteke12@gmail.com` (verification codes are readable in the owner's Gmail), then document it in `ACCOUNTS.md`. Never paste passwords into chat; store them as described in `ACCOUNTS.md`.
6. **Look before you deliver.** Render a thumbnail of every character and of sample frames; a "Survivor" model once turned out to look like a zombie. The owner must see the cast before the film is rendered.
7. **Videos are the deliverable.** The owner judges by watching. Deliver an MP4 (and the project zip). Say plainly what is autopilot/scripted, what has no sound, and what looks worse than the real renderer.
8. **Honesty about limits.** No GPU in the agent sandbox → software rendering (~0.5 s/frame at 1600×900). Mixamo = body motion only (no face/lips). Say so.
9. **Document everything here.** Method, accounts, lessons — so the next agent can continue without the owner repeating himself.
10. **Security.** Remind the owner to rotate any password he shared in chat. Never commit secrets to a public repo.
